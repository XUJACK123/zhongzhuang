# 单次 +10° 实机尝试（2026-11-09）

用户明确授权直接尝试10°，并要求小幅、缓慢。仅执行了一次。

- CAN_ID=2，MST_ID=0，MIT模式，PMAX=12.5，VMAX=45，TMAX=54。
- 目标+10°，速度目标上限2°/s；力矩目标缓升0.10 Nm/s，限幅±0.50 Nm。
- MCU独立守护：最多12秒；反馈速度10°/s、位移12°、反馈丢失/控制故障均停止。
- 启动前阶段READY，反馈新鲜，驱动器29℃、电机26℃，CAN收发错误0。
- 专用DIRECT_TEST=1固件默认不运动；写g_direct_start_request=1后仅允许一轮，结束后拒绝重复触发。

结果：phase=3、result=2（12秒超时停止），elapsed_ms=12000，start_deg=0、final_deg=0、delta_deg=0。
有效样本118个；编码后力矩峰值0.487911224 Nm。指令从约0.09、0.17、0.28、0.36逐渐升至0.488 Nm。
反馈角度始终0°。速度反馈在零速附近量化格点跳动，不能据其小数值认定实际发生旋转。
使能命令计数1，运行阶段drive=2/active=1/target=10；目标报文已进入CAN消息RAM，CAN无错误。

因此此次排除了“没有触发控制/始终只发送失能”的解释，但并未证明电机执行了运动命令。
可能仍涉及电机实际输出、负载/机械约束、固件指令解释等；本次没有继续提高力矩或再次运动。
测试结束后先重复覆盖中性MIT目标，再请求失能；实际失能反馈仍需单独确认，不能声称测得零电流。
