# M3508：遥控器每次双上档转动 10°

默认固件：STM32H723 + C620 + M3508（1号），CAN2，DBUS 遥控器。
构建产物 build/c620_m3508.elf；VS Code 选择 DAP，F5 编译/烧录，停在 main 后继续。

## 操作规则

1. 开机或遥控器/电机反馈恢复后，先将两个拨杆都放在下档至少100 ms，完成解锁。
2. 两个拨杆都切到上档并稳定40 ms，触发一次 **输出轴 +10°**。
3. 持续保持双上档不重复触发。到位并稳定150 ms后自动零电流，不继续位置保持。
4. 离开双上档（包括双下档、中档或拨杆不同档）立即取消本次动作并发送零电流。
5. 离开双上档稳定40 ms后，再次双上档会从当时实际位置再走 +10°。
   正常完成时位置依次约10°、20°、30°；中途取消的剩余角度不会留到下一次。
6. 遥控器或电机反馈超过100 ms未更新、CAN bus-off、过温、超速、控制周期异常或动作超过12 s，停止输出并锁定；
   故障消失后要重新双下档100 ms解锁。CAN bus-off 不会自动重新初始化。

零电流不等于机械抱闸。电调掉电、CAN断线时不能保证零电流报文送达。
仅对固定好的单电机进行初次验证，软件限流/超时不能替代机械安全措施。

## 接口与控制

- 遥控器：DM-MC02 板 DBUS/P6接口，板载反相后进入 UART5_RX/PD2/AF8。
- UART：100000 baud，8数据位、偶校验、1停止位；通过RX中断和IDLE界定18字节帧。
  没有使用DMA，也不依赖DMA缓存区域。
- 电机：CAN2，PB6=TX、PB5=RX，经典CAN 1 Mbps；使用板载CAN收发器。
- 1号电机命令ID=0x200，反馈ID=0x201；命令组内其余3个槽位为0。
- 位置通过8192线转子编码器累计多圈，按实际反馈到观察轴的有效比值换算角度，当前 M3508_FEEDBACK_RATIO=1.0；不再自动套用19.2倍减速补偿。
  电机断联期间的转动不做猜测累计；显示角度是上电后的相对角度。
- 控制器为位置P -> 限速目标 -> 转子带限加速度的速度目标 -> 编码器差分/低通测得速度的PI -> C620电流指令。
  默认目标速度上限3°/s，加速度上限2°/s²，电流指令限幅±1000（约±1.22 A）。
  控制器增益未做实机整定，达到10°的精度/稳定性需要台架验证。

参数在 Core/Inc/m3508_step_config.h；电机ID在 Core/Inc/c620_can.h。
正转定义为编码器正方向。此处有效比值不是名义机械减速比；用户实测旧版10°接近180°，故本次先去掉额外补偿。新角度仍需轴端刻线校准。若新目标10°实测为A°，有效比值应乘以10/A；未校准前不能宣称实物精确10°。

## Live Watch

| 变量 | 含义 |
| --- | --- |
| g_remote | 已验证的遥控帧、right_switch/left_switch、帧计数、时间戳；上=1，下=2，中=3 |
| g_remote_fresh / g_motor_fresh | 当前链路是否新鲜有效 |
| g_remote_rx_bytes | UART已收到的字节数 |
| g_remote_bad_frames / g_remote_uart_errors | 帧长度/内容错误及奇偶校验、噪声、溢出错误 |
| g_step.armed | 已通过双下档解锁 |
| g_step.active | 正在执行10°动作 |
| g_step.step_count / completed_count | 已触发/已完成次数 |
| g_step.target_deg / error_deg | 输出轴目标角度及误差 |
| g_step.fault | 0正常；1遥控无效；2电机反馈无效；3CAN异常；4过温；5超速/非法数值；6周期超时；7动作超时 |
| g_m3508_position_deg / speed_deg_s | 输出轴相对角度/速度 |
| g_c620_current | 控制器本轮实际电流指令；每轮覆盖，不能通过手改变量绕过拨杆权限 |
| g_c620_feedback | 原始编码器、多圈累计、转子RPM、电流反馈、温度和帧计数 |
| g_can_tx_queued / failed / bus_off | 发送FIFO提交计数、失败计数和bus-off状态 |

进入零电流时会请求取消FIFO内尚未发送的非零指令，并继续周期发送零电流。

## 构建和验证

- 默认：mingw32-make -j4 all DEBUG=1，输出 build/c620_m3508.elf/.hex/.bin。
- VS Code：Ctrl+Shift+B 编译，DAP/STLink/JLink 的 launch 配置均加载 M3508 ELF。
- 保留的DM8009：仅显式使用 DM8009=1 时构建，不能用默认M3508调试ELF连接它。
- 被动CAN诊断：DIAGNOSTIC=1（与默认遥控器位置程序独立）。

已通过 ARM GCC 交叉编译及 tests/test_m3508_step.c 主机测试：DBUS非法帧、拨杆去抖、单次触发、重复步进、
双下档零电流、断联恢复、CAN错误、温度、超速、动作超时、编码器跨圈，以及简化闭环模型的到位测试。
简化模型不等于电机实测；当前新功能尚未烧录或进行遥控器/电机联调。

参考：DJI M3508 P19 官方手册的约19:1减速结构与C620接口；本工程实际减速比由配置文件指定。
