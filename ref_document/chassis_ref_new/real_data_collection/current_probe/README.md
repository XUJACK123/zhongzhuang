# 单电机电流—运动响应采集

按用户最新指示沿用已选 STEP 几何，暂停重复尺测，优先收集力相关数据。这里测量发送/反馈电流、原始电机输出角度和速度；Nm 由名义 Kt=1.261575 Nm/A 换算，不是独立轴端力矩实测。无测力仪，不能从这些数据唯一分离弹簧力、摩擦、重力和效率。

独立固件 `build/current_probe/current_probe.elf`，版本 0xC2611171。正常 RL 镜像、权重、方向/零点标定不改。每轮只使能选择的 DM 电机，其他 DM 发 FD，所有其他电机命令为零，双轮零电流。单次波形为 1 s 线性升流、0.5 s 保持、0.5 s 卸流，名义幅值硬上限 3 Nm（2.378 A）。默认 DM2 +0.5 Nm；真实 S1 中档仅待命，还需要一次新软件令牌。

由于已发现关节符号/零位疑点，本诊断不运行关节位置闭环或 RL，也不把原 q 膝范围判据用于电机轴微动。保护使用每台电机的原始编码器相对输出轴角度：腿轴 2°/0.15 rad/s、轮轴 5°/1 rad/s；从使能前锁存起点，并保留真实遥控下档/失联、摇杆居中、反馈超时、解缠失锁、CAN、温度、倾倒和周期超时停止。新版本不能视作原关节标定已修复。

**数据语义**：本版本 trace 的 q/qd 是“原始计数正方向的电机输出轴角/速度”，不是髋膝广义坐标。10 ms 轨迹保存全程，2 ms 停机事件保留触发时刻。轮径、几何或轴端力矩真值不可由这组 q 直接推出。

构建：`python real_data_collection/current_probe/build.py`；并运行原工程 `mingw32-make test`、`mingw32-make`。主机测试覆盖原始电流正负极性、只有选定电机出力、参数锁存、遥控最后检查、反馈丢失、速度/位移/时间停止、单批停机和看门狗。主机通过不能替代真机行为记录。

显式烧录工具 `flash_stopped.py --previous-elf <已知当前ELF> --out <新目录>` 要求下档、STOP，先备份/核验旧加载段，再烧录验证，绝不发运动令牌。真机操作已由用户授权，当前固定悬空。

`run_one.py --index 0|1|3|4 --raw-nm <±0.1..3> --name <新记录名>` 明确执行一轮：清日志、触发、等停止、读完整缓存并分析。索引 0/1/3/4 分别 DM4/DM3/DM1/DM2，必须先归档上一轮再使用。正负是 DM 原始电流极性，不直接称为收腿/伸腿。每轮后检查数据再决定下一轮；不自动重复、升流或解除故障。

分析：`analyze.py diagnostics/<name>_trace`。0.3516°并连续三帧的变化只是本次“可检测运动”的判据，不能当作静摩擦系数或独立关节负载。自由悬空时同侧两电机可能联动。
