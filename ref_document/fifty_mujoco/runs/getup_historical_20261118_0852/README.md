# 用 11 月 13 日编码器数据复核与续训起身

输入为 17:39:44 和 20:54:41 的 CAN 快照及当晚关节参考位。两份原始记录缺机身姿态和接地标签。20:54 的腿关节计数与 21:51 档案接近，使用每个腿电机 ID 最常出现的值。输入和标定的 SHA-256 见 [MuJoCo 回放报告](mujoco_replay.json)。

**直接回放。** 在水平、横滚 ±8°、俯仰 ±12° 五种假设下，保留编码器回算的关节角，最低轮胎放至距水平地面 2 mm，电机命令与外部辅助均为零。17:39 五次因膝关节限位退出，水平假设下初始机身净空 223 mm。20:54 五次因 C 观测器无效退出，水平假设下初始机身净空 207 mm。快照存在关节绝对标定、侧别和地面条件的不确定性。 [原始姿态与坐地候选对比](mujoco_comparison.png)

**训练初态。** 从当前 MuJoCo 坐地基准出发，保留部分历史膝角偏差，再求使两轮与底面同接触平面且轮轴在髋后的髋角。144 个候选中 54 个通过 3 秒零输出静置，其中 30 个用于训练，24 个使用不同横滚/俯仰组合留作评估。17:39 来源 9 个，20:54 来源 45 个。后续 1 秒复核中，各组内腿角峰峰差不到 0.000001 rad。当前物理模型将候选收敛到几乎相同的腿部停位，因此不能把训练改善单独归因于历史初态。

短训包含 CPU 与 GPU 的历史派生初态组，以及只用原始仿真初态的同设置对照组。短训开发集轻扰动下，原策略 13/20、历史组最好 17/20、对照组最好 15/20。

一小时续训于 09:12:35–10:12:52 完成。GPU 分段训练起身动作与观测触发时机，共 169 轮、47,320 场。CPU 在相同历史派生初态上搜索接管平衡的动作输出修正，共 74 轮、7,252 场。 [训练时间表](hour_extension/schedule.json) · [分段日志](hour_extension/stages.jsonl)
