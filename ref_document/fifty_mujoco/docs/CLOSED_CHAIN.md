# 闭链模型：离线数值修正后的状态

> 2026-10-31。当前主启动指南为项目根 progress.md §25。本轮未运行 MuJoCo、CUDA、pytest、训练或 SolidWorks。

## 几何依据

URDF 决定关节坐标和安装偏移，平面长度通过对单位关节轴的垂直投影得到。左右大腿/小腿均为 210/250 mm，末端连杆 96.600 mm。mechanism/resolve.py 读取实际 URDF，校验连接关系、轴平行性、长度和左右独立侧向偏移；机构求解与 build_closed_mjcf.py 共用这个解析入口，不再通过移动 CAD 节点补偿三维距离。

正下方参考绝对杆件角为 −2.115162642 / −1.120740360 rad，基座高度 0.464751372 m。主动曲柄平面绝对角 −1.026430011 rad 必须经模型零位转换，不能直接写 qpos。旧串联默认角保持原样，其轮心在髋前方 22.865 mm。完整初始化必须同时设置主动和被动关节、基座姿态、速度、控制量与历史状态。

## 候选训练模型（2026-10-31，未编译）

`assets/mjcf/fifty_closed_train.xml` 由 `assets/build_closed_mjcf.py` 生成。它把串联模型
已经做对的三件事继承过来，而不是重新发明：

| 项 | 来源 | 验证方式 |
|---|---|---|
| 质量 / 质心 / `fullinertia` | `fifty_train.xml` 的 `r0_link` / `r1_link` / `wheel`，按 `R·I·Rᵀ` 旋转到新 body 系 | 质量守恒到 1e-12；惯量迹不变 |
| 碰撞几何 | 同上（底板 box、腿胶囊、**轮 0.06 m 圆柱**） | XML 里没有 `sphere` |
| 弹簧锚点 | `mechanism.yaml` 的实测点 + 11 mm 侧向差 | `authored.spring.*.lateral_gap_mm == 11.0` |

四个环杆（曲柄、推杆、三元板、末端连杆）没有串联对应物，各 0.030 kg，**从大腿/小腿里扣**，
所以每条腿的总质量与串联模型完全相等。

`<keyframe name="reference">` 存的是**已闭合**的参考姿态（见 `mechanism/closed_pose.py`），
reset 从它开始，而不是让求解器去收敛。

| 关节（右） | qpos (rad) |
|---|---:|
| `rf0_Joint`（大腿） | 1.738502588860534 |
| `rf1_Joint`（**曲柄**） | 0.896101201772943 |
| `r_knee_Joint` | 1.004773771416566 |
| `r_pushrod_Joint` | 1.629830019256905 |
| `r_ternary_Joint` | 1.004773771391616 |
| `r_endlink_Joint` | 1.738502588860534 |

左侧是同值取负（腿铰 −Y），两轮共用 +Y 且为 0。

> **不要和串联模型的那组数混用。** 串联参考姿态是 `rf0 = 2.1152`、`rf1 = -2.5652`；
> 闭链是 `1.7385` / `0.8961`。同一个物理姿态，两套坐标系。

### 还没验证的（必须有 MuJoCo）

编译；`<connect>` 的约束秩（`nv − 2·neq = 12` 是数出来的，不是秩检查）；
编译后两环是否仍闭合在 1e-9 m 内；keyframe 下弹簧长度是否 227.760939 mm；
动力学是否稳定。`tests/test_closed_chain.py` 覆盖的全是不用编译就能判定的部分。

### 仍留在模型里的占位

1. 铰范围是 ±3.2 rad 的宽松盒（真实闭链可行域未知），被动关节与轮不受限；
2. 弹簧是 **450 N 常数**，没有刚度，`authored.spring.model` 明确写了
   `constant_force_placeholder`；
3. 电机限幅沿用串联模型的暂定值（腿 30 N·m / 轮 5 N·m）；
4. 各连杆内部的质量分配是建模选择，不是 CAD 值。

## 成为训练模型前必须补齐

1. 候选模型单独版本化，加入地面、有效碰撞、正确网格安装变换与用户已接受的质量/惯量。骨架惯量为占位，不能按原质量相近就认为惯量已继承。保留质量分组与平行轴变换依据，避免重复计算连接件。
2. 轮半径使用接受的 0.06 m；旧骨架为 0.055 m。左右轮连续转动，去掉旧 ±3.2 rad 轮关节限位；左轮有效轴须与契约 +Y 一致，修正旧骨架 −Y 的差异。
3. 接入真实弹簧锚点和 11 mm 侧向错位，三维销距及三维力/力矩均一致。名义 450 N、允许销距约 175–250 mm；首轮可用显式常力近似。不能直接把旧锚点 300 N 改为 450 N；弹簧不得受电机 enable 控制，也不能在两处重复施力。
4. 主动曲柄驱动替代串联膝驱动，统一正负号、零位、传动比、速度与电机限幅。保留 25/125/6 接口需要实际坐标转换，不是只保留向量长度。
5. CPU 环境的刚体/执行器/弹簧名称和 WarpEnv 的模型路径仍绑定旧串联模型。改为共同的模型版本选择与名称映射，再适配 spawn、通道检查、spring-audit、contact-test、contract-test、gpu-parity、训练及评估入口。
6. 生成完整非奇异闭链初态，检查被动关节、约束秩、左右装配支路、轮地关系和弹簧行程，完成重置与图重放验证。

完成这些后才能依次进行候选模型编译、初始化、CPU 短仿真、契约与 CPU/GPU 对拍、20 updates 冒烟。旧骨架缺地面、碰撞、弹簧和正确惯量，不能直接开始正式训练。摩擦实测与完整力曲线留待后续改进，当前首要缺项是模型与环境集成。
