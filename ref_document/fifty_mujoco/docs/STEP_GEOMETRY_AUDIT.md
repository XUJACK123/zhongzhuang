## 2. 方法：这次比上一版多做了什么

| 环节 | 做法 | 为什么必须这样 |
|---|---|---|
| 读文件 | latin-1 分块流式读取，只保留结构/几何相关实体 | DATA 段是 ASCII + `\X2\` 转义；按 UTF-8/GBK 读会失败 |
| 实例变换 | 解析复合实体 `REPRESENTATION_RELATIONSHIP_WITH_TRANSFORMATION` | 只匹配 `#id = TYPE(...)` 会得到 0 个变换 |
| 零件名 | 解码 `\X2\`（UTF-16BE 十六进制） | 否则中文名全是乱码，任何名称检索都返回空 |
| 圆柱归属 | `SHAPE_DEFINITION_REPRESENTATION → SHAPE_REPRESENTATION → MANIFOLD_SOLID_BREP → CLOSED_SHELL → ADVANCED_FACE → CYLINDRICAL_SURFACE` | 不建立这条链就只能得到一堆无名圆柱 |
| 名字归属 | 只从**叶子零件**的命名 rep 传播一跳，且绝不覆盖已有名字 | 对全部 1004 条关系做并查集会合并成一个名字（第一次尝试即如此失败） |
| 轴线 | `AXIS2_PLACEMENT_3D` 的局部 +Z 即圆柱轴；两轴距离取公垂线距离 | 同一零件内的两轴距离**不依赖**未验证的装配变换约定 |

本次解析：530 个 representation、582 个实体、23945 个圆柱面，其中 **20219** 个成功归属到零件。

## 8. 这些数字能用来做什么、不能用来做什么

**可以用**：

- 用 G01/G02 核对当前等效串联模型的 0.21 / 0.25 m 腿段尺寸（已一致）。
- 用 G03–G07 开始建立闭链（五连杆）几何：前推杆 135、末端连杆 96.6、中间三孔件 135/67/200.51。
- 用第 5 节的轴组确定各零件的旋转轴方向与相对位置，作为 `configs/mechanism.yaml` 的 `cad_extracted` 初值。

**不能用来**：

- 直接替换 MJCF 的关节零位与限位：轴方向已知，但零位、正方向和可行范围仍需装配配合确认。
- 证明质量/惯量正确：本工具没有任何质量信息。
- 生成闭链约束：拓扑（谁和谁同轴、哪两个零件固连）必须由人确认。

## 10. 仍需在 SolidWorks 中完成

1. 用两个已知零件核对 `A1·A2⁻¹` 约定；不符则取逆并更新本文件。
2. 确认第 5 节里哪一组轴是髋轴、膝轴、轮轴，以及前推杆/末端连杆的连接端。
3. 记录各关节的零位（装配姿态下的角度）与正方向。
4. 确认两侧气弹簧的真实锚点（缸体端 / 活塞杆端属于哪个零件、局部坐标多少）。
5. 读取材料与质量属性；STEP 里没有，只能从 SLDASM 或实测获得。
6. 结论按 `cad_extracted` 记录，不得直接写 `measured`。
